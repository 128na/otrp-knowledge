# 道路・線路・電化・航送・航空

> この内容は、OTRP の PR とリリースノートの記述から拾い、OTRP v63_4 のソースコードと照らし合わせたものです（2026-11-21）。ゲームを動かしての確認はしていません。仕様は [OTRP wiki](https://github.com/teamhimeh/simutrans/wiki/OTRP-Home) が正です。

道路・線路（way）の属性と建設、電化・架線、路面電車（併用軌道）、斜めタイルの way の共存、航送、飛行機まわりの、wiki に載っていない（または wiki より新しい）仕様をまとめる。

## 電化・架線

### 電車の非電化区間への直通条件と出力（v44_4 から v49）

- v44_4（#95）: 電車以外の車両と連結していれば、電車も非電化区間へ直通できる。条件は「非電化の車両と連結している」ことと「その車両の出力が 0 より大きい」こと。客車など出力 0 の車両と連結しても直通は有効にならず、電化区間しか走れない。
- #95 の時点では、非電化区間でも電車の出力は有効のままだった。
- v49（#235・#238・#239・#240）で、次の駅までの区間が非電化区間のとき電車の出力を 0 にする仕様に変わった。編成ごとに、次の 3 つの状態を持つ。

| 状態 | 意味 |
|---|---|
| 電車を含む | 編成（連結中の編成も含む）に電車がある |
| 電気が要る | 電車を含み、電車以外で出力が 0 より大きい車両が無い |
| 電気を使って走行中 | 電車の出力が有効（このとき架線の最高速度も参照する） |

- ルート検索は「電気を使うルート（電化区間だけ）」「電気を使わないルート」の 2 回に分けて行う。電気を使うルートで行けるときは電気を使って走行し、行けないとき（電気が要る編成でなければ）電気を使わないルートを探す。
- #238: 振り分け信号で空きホームが無く、非電化側へ入ると電気を使わない扱いになって再加速時の出力が極端に落ちる不具合を直した。
- #239・#240: 古いセーブを読むと電気を使って走行中かどうかが不正確になり、速度が出なくなる場合があったため、v50 より前のセーブはロード時に、残りの経路に非電化区間があるかどうかで再計算する。
- v49 のリリースノートによると、電車を連結した編成は電化区間を通るルートを優先して検索する。非電化区間を強制的に走らせるときは、非電化区間内に中継点を置く。

- 出典: [#95](https://github.com/teamhimeh/simutrans/pull/95)（2025-05-25 マージ）、[#235](https://github.com/teamhimeh/simutrans/pull/235)（2025-12-28）、[#238](https://github.com/teamhimeh/simutrans/pull/238)（2025-12-28）、[#239](https://github.com/teamhimeh/simutrans/pull/239)（2025-12-28）、[#240](https://github.com/teamhimeh/simutrans/pull/240)（2025-12-29）、リリース v44_4、v49
- 関連する wiki: [電化の取り扱いについて](https://github.com/teamhimeh/simutrans/wiki/%E9%9B%BB%E5%8C%96%E3%81%AE%E5%8F%96%E3%82%8A%E6%89%B1%E3%81%84%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6)（v49 以降の仕様の概要は記載あり。出力 0 の車両と連結したときの扱い、フラグ名、旧セーブ読み込み時の再計算は記載なし）

### 一部だけ電化されていないホームへの振り分け（v48_2）

電車を、一部だけ電化されていないホームへも振り分け信号で入れるようにした。v48_2 のリリースノートは「一部が非電化で、電化区間の有効長が十分なホームに電車が振り分けられない問題を解消」と説明している。

**wiki との違い:** wiki「信号システムについて」の振り分け信号の項は「一部だけ電化していないホームについては電車が入線できません」と書いているが、v48_2（2025-12-22）で変更されている。wiki「電化の取り扱いについて」の「一部のみ電化されているホームでは電化されている長さを加味」は、この変更後の説明と合う。

### 架線の最高速度を参照する条件

- v46（#176・#188）: 電車以外は、架線（wayobj）の最高速度を参照しない。鉄道以外（モノレール・マグレブ・道路など）にも同じ扱いを広げた。船と飛行機は wayobj の検索自体をしない。モノレールなどで way と wayobj の最高速度を切り替えたとき、wayobj の最高速度が更新されない問題も直した。
- v50_3（#289）: 電車が架線最高速度を参照するのは、実際に電気を使って走行するときだけにした。以前は電気が要る編成でも参照されない場合があった。
- v50（#246）: 電気を使わずに走行しているとき、編成詳細ウィンドウで電車の出力を 0 と表示する。
- v51_2（#366）: トロリーバスなど電化された自動車の出力が 0 になって加速できない不具合を直した。

### パンタグラフ下げ画像の選び方

電気を使わずに走る電車（非電化区間を走る電車）の積載画像として `No_Electric` を使う。反転中は `Reverse_No_Electric` があればそれを使う。対象は電車（電気の動力の車両）だけで、積載画像（freightimagetype）の種類として dat で指定する。使うには `good.No_Electric.pak`・`good.Reverse_No_Electric.pak` が要る。v52 で追加された。
- 反転中に `Reverse` と `No_Electric` の画像があり `Reverse_No_Electric` が無いときの選ばれ方は、画像の並び順で変わる。
- コードでは確かめていない。

## 路面電車（併用軌道）

### 併用軌道を他の軌道の上に敷設する

- v44_4（#94）: 路面電車用の併用軌道（waytype が `tram_track` の way）を、モノレール・ナローゲージなど他の軌道の上に敷設できる。本家 124.3.1 までに入った 2 つのコミットの移植で、OTRP ではさらにトンネル内でも併用軌道を敷設できる。
- v49（#230）: トンネル内で、鉄道トンネルから分岐し、別の属性のトンネル上の併用軌道へつなげられる。古いマイナーバージョンで読んでセーブデータが壊れるのを防ぐため、v49 で入れた。
- v46_1（#193）: モノレールなどの上の併用軌道で予約を解放するとき、モノレール側の予約も解放する。
- 内部では、併用軌道も鉄道（track）の way として扱われ、専用軌道と併用軌道の両方を同じ種類の way が表す（#165）。
- コードでは確かめていない（他の軌道の上への敷設、トンネル内での扱い、予約の解放）。

### 路面電車を鉄道車庫で扱う（v53）

- 車庫の「路面電車を表示」ボタンで、tram 車両を鉄道車庫に表示する。車庫の中で、編成・スケジュールや路線の設定・出発・格納・連結ができる。
- 同一会社同士であれば、鉄道編成と路面電車編成を連結したまま入出庫できる。ただし 1 つの編成の中に鉄道車両と路面電車車両を混ぜることはできない（スケジュールなどの属性がおかしくなるため）。混ぜたいときは編成同士の連結機能を使う。
- v53 で入った車庫の転送先選択と、車庫から車庫への転送も、tram の鉄道車庫への転送に対応した。
- 連結の不完全な編成を組む車庫のボタン「連結の不完全な編成を許可」（allow invalid convoy）を使っても、路面電車と鉄道の連結だけは無視できない（#451）。
- v63_1_2 で、鉄道車庫で路面電車編成をコピーできない不具合を直した。
- コードでは確かめていない（「路面電車を表示」ボタンが鉄道車庫にあることだけ確かめた）。

- 出典: [#425](https://github.com/teamhimeh/simutrans/pull/425)（2026-03-29 マージ）、[#449](https://github.com/teamhimeh/simutrans/pull/449)（2026-03-31）、[#451](https://github.com/teamhimeh/simutrans/pull/451)（2026-04-21）、リリース v53、v63_1_2
- 関連する wiki: [OTRP-Home](https://github.com/teamhimeh/simutrans/wiki/OTRP-Home)（「路面電車車両/編成を鉄道車庫に表示」の 1 行のみ）

## 道路

### 追い越しモードの追加（「一編成専用区間」・「追い越し車線は停車のみ可」）

追い越しモードに 2 種類が加わった。wiki の OTRP-Home の [E] 一編成専用区間、[S] 追い越し車線は停車のみ可、に当たる。道路の設定の画面では「一編成専用区間」（exclusive area）、「追越車線は停車のみ可」（passing lane stop only）と表示され、スクリプトでは定数 `exclusive_area_mode`・`passing_lane_stop_only_mode` で指定する。どちらも、走り方は「追越禁止」（prohibited）と同じで、そこに規則が足される。

| モード | 内容 | 使い方の例 |
|---|---|---|
| 一編成専用区間 | このモードの道路でつながった範囲に、同時に 1 編成しか進入できない（範囲は 256 マスまで調べる） | 行き違いできない道路、鉄道転換 BRT の再現、連結時に他車が進入して起きるデッドロックの回避 |
| 追い越し車線は停車のみ可 | 停車する場合に限り、追い越し車線に停車できる | 駐車場での交互停車 |

- 一編成専用区間の例外: 自分と連結している編成は妨げにならない。停車中の車両が連結待機をしていて、進入しようとする車がその編成と連結できるときは、進入できる。

**wiki との違い:** wiki の [E]・[S] の説明に、連結待機の編成への進入の例外は書かれていない。

- 出典: [#735](https://github.com/teamhimeh/simutrans/pull/735)（2026-09-19 マージ）
- 関連する wiki: [OTRP-Home](https://github.com/teamhimeh/simutrans/wiki/OTRP-Home)（概要のみ）

### 道路建設中の接続方向の矢印

建設中の道路に、接続予定の方向の矢印が出る（v47 で追加、wiki にもある）。表示のルールは次のとおり。

- 一方通行のときは、敷設する方向を常に表示する。
- 両方向では方向を表示しない設定のときは、両方向の道路の敷設でも表示しない。
- 表示するのは、既存の道路の接続方向との合算（終端のマスには例外がある）。
- 橋とトンネルでも表示する（v47_1）。表示の改善は v48_1（#225）。

- 出典: [#200](https://github.com/teamhimeh/simutrans/pull/200)（2025-11-22 マージ）、[#206](https://github.com/teamhimeh/simutrans/pull/206)（2025-11-29）、[#225](https://github.com/teamhimeh/simutrans/pull/225)（2025-12-20）、リリース v47、v47_1、v48_1

### 車両の描画オフセットの設定キー（左側通行）

左側通行時の車両の描画オフセットと、追い越し車線走行時のオフセットを、`simuconf.tab` で設定できるようにした。リリースノートでは「左側通行時、追い越し車線走行時のオフセット」の設定として v50_4 に載っている。

- キーは `driveleft_base_offset_<方角>`（左側通行時）と `overtaking_base_offset_<方角>`（追い越し車線走行時）。方角は `south`・`west`・`southwest`・`southeast`・`north`・`east`・`northeast`・`northwest` の 8 つで、値は x と y の 2 つの整数。
- 既定値: 左側通行時は x が 12、y が 6 を基準に、方角ごとの向き（符号）を掛けた値。追い越し車線走行時は、指定しなければ左側通行時と同じ値。

- 出典: [#307](https://github.com/teamhimeh/simutrans/pull/307)（2026-01-24 マージ）、リリース v50_4
- 関連する wiki: [OTRP-Home](https://github.com/teamhimeh/simutrans/wiki/OTRP-Home)（v51 の simuconf.tab による全車両の一括オフセットのみ。この 2 つのキーは記載なし）

### 市内道路を別の道路で上書きしたときの制限速度

公共事業ではないプレイヤーが市内道路（city road）を通常の道路で上書きしたとき、制限速度も上書き後の道路に合わせて更新される。市内道路の歩道に由来する 50km/h の制限が、歩道の無い高速度の道路へ置き換えた後も残る問題を直した（v56）。

## 勾配・高架・橋

### 高さ 1 の高架と 0km/h の way

- `way_height_clearance==2` のとき、高架のオフセットを `-1` にすると、高さ 1（ハーフハイト）の高架を建設できる。下に way が無い場合だけ建設でき、何も無い地形は高架の 1 段下まで上げられる。way がある場合は従来どおり 2 段以上で立体交差する。橋は `height_offset=-1` で敷設した高架に接続できる。入力できる範囲は `1-way_height_clearance` から 32（v50_2、#281）。
- 最高速度が 0km/h の way は、1 段上の高架を通せる。`way_height_clearance==2` での確認結果（#689、v58_3）は次のとおり。
  - 速度がある線路の 1 段上は通せない。
  - 速度 0 の線路の 1 段上は通せる。
  - 1 段橋梁の上に `offset=0` の高架を敷設するとき、橋が速度ありなら交差できず、速度 0 なら交差できる。
- v50_3（#297）: 0km/h の線路を撤去ツールで撤去でき、0km/h の線路に架線や信号を設置できる。
- #277（高さ 1 の橋の下に建物を建てない）は、速度 0km/h の way を 1 段高架下に敷けるようになり、アドオン側で対応できるため、却下された（2026-03-27）。

### 橋の上への高架建設（v58_0_2）

- 橋と同じ高さの地面が続く場所での橋越え。

### 建物の上空の高さ制限（`height clearance`）

建物アドオンに、許可された上空の高さ制限を設定できる。高さ制限より低い高架線は建物の上に建設できない（制限と同じ高さなら建設できる）。逆に、建物を建てるとき、真上から高さ制限の段数までの間に高架や橋があると建設できない。未設定のアドオンは、建物の全タイル・全配置のうち一番高いタイルの高さから自動で算出する。makeobj 60.12 で追加された機能で、v62_4_1 で有効になった。dat のキー名は確かめられていない。

### 勾配の抵抗値（tile_height が 16 でない pakset）

1 段の高さが 16 でない pakset（ハーフハイトなど）で、坂道の抵抗値を修正した。v51 のリリースノートでは、勾配の摩擦係数を旧坂基準と現行基準で切り替えられる変更（#215）として載っている。

- 切り替えは、設定「古い勾配の摩擦係数を使用」（`use_old_friction`、既定は OFF）で行う。
- 古い基準（ON）: 登りは 23、下りは −13 に、勾配の高さ（1 段か 2 段）の二乗と、（1 段の高さ ÷ 16）の二乗を掛けた値を、摩擦に足す。1 段の高さが 8 の pakset では、高さ 16 の pakset の 4 分の 1 になる。
- 現行の基準（OFF）: 登りは 15、下りは −7 に、勾配の高さの二乗だけを掛けた値を足す。1 段の高さには左右されない。

## 線路の予約とすれ違い

### 4 方向分岐で対角の辺を同時に走る（v58_0_2）

4 方向分岐で、「北と西」「東と南」のように対角の辺を、同時に走れる。これで斜めタイルの複線の間隔を狭められる。振り分け信号にも対応している。

- 南北の直進と東西の直進は、タイルの中央で交差するので、同時には予約できない。許可するのは、交差しない向かい合わせのカーブだけ。
- 経路の判定は、進入方向だけでなく、進入と退出の方向の組で行う。1 つのタイルで予約できる編成は 2 つまでになった（先に予約した編成と、後から重ならない向きで予約する編成）。
- 手動テストで、振り分け時の直交は進入不可、斜めは並走できる、逆走もできる、と確認された。
- v58_0_2 のリリースノートには、この版に線路予約のバグがあり、v58_2 を使うよう書かれている。

- 出典: [#584](https://github.com/teamhimeh/simutrans/pull/584)（2026-07-17 マージ）、リリース v58_0_2

## 航送

航送（船が鉄道・自動車などの編成を運ぶ機能）は v61_0_2 で入った（#722 は 2026-09-09 マージ）。その後の変更のうち、wiki「航送機能」に無いものは次のとおり。

- 運ぶ側は船に限らない。船以外も航送する側になれる（#722 の確認項目）。
- 乗船した自動車（road_vehicle）の、駅の停車タイルの予約を解除する。乗船で空いたスロットを、他の編成が振り分け標識で使える。
- v62_0_3（#740）: 航送の通行料の比率を、道路などの通行料とは別の設定に変えた。航送が終わるとき、航送された編成の積載物の運賃の一部を、航送した側が受け取る。次の 2 つの比率は、どちらも「高度な設定」と simuconf.tab で決める。
  - `toll_shipping_percentage`: 航送する側の車両の運行費のうち、航送される編成が通行料として払う割合（%）。指定しなければ `toll_runningcost_percentage` と同じ値になる。自社の編成同士では払わない。
  - `shipping_income_percentage`: 航送された編成の運賃収入のうち、航送した側が受け取る割合（%）。既定は 0。
- v62_0_3（#750）: 航送の開始処理を、乗降と連結解放のあとに行う。航送を始める駅で、旅客・貨物の乗降ができる。
- v62_5_1（#785）: 連結中の子編成も、他の編成を航送できる。
- v63_0_1（#774）: 航送の単価（航送する側が受け取る額）を waytype の組み合わせごとに設定できる。キーは `revenue_<航送される側>_shipped_by_<航送する側>`（例: `revenue_road_shipped_by_water`）。単位は、1 マス進むごと・航送される編成の長さ 1 マスごとの 1/100 クレジットで、既定は 0（課金しない）。航送された編成の所有者が、航送した側の所有者へ通行料として払う。自社の編成同士では払わない。

**wiki との違い:** wiki「航送機能」の航行費用の節は、通行料の式を `toll_waycost_percentage` で説明している。v62_0_3（2026-09-26）で通行料の比率は `toll_shipping_percentage` に変わり、運賃収入の分配（`shipping_income_percentage`）も加わった。wiki は 2026-11-18 の更新で「v63 以降は waytype ごとに航送単価を設定できる」と足したが、設定のキー名と、式の比率の変更は書いていない。

## 飛行機・滑走路

### 滑走路の振り分け（v62_4_1）

滑走路が空いていなければ、着陸待機の旋回をする。旋回中に他の滑走路を探し、空いていれば経路を変えて別の滑走路に着陸する。複数の滑走路のある空港で、1 本に集中しなくなる。

- 経路の検索は、スケジュールで指定したタイルへの経路で行う。指定したタイルから空路の way でつながっている滑走路の端だけが候補になり、指定した駅につながっていない滑走路には、先に同じ駅扱いの駐機所があっても振り分けられない。
- 一方通行標識で禁止された滑走路にも振り分けない。
- v62_5_1（#788）: 飛行機の誘導路で、他社進入禁止標識が有効になった。他社進入禁止を置いた経路しかない滑走路へは振り分けない。

- v62_5_1（#782）: 飛行機の駅を直線タイルや斜めタイルに置くことが禁止されていなかったため、機能が動くよう直した。反転描画は折り返しのタイルだけ有効。駅の情報にホーム長を足した。

### 港の近くの海に中継点を置いたとき（v45_3）

飛行機のスケジュールで港周辺の海に中継点を置いても、停車駅とは扱われなくなった。以前は輸送できない旅客の経路ができていた。停車できる駅かどうかを、編成の waytype に合う way があるかで判定する。waytype を限定しない判定では、水上マスの港を停車可能として扱う。

### 飛行機の反転出発と飛行高度

- v45_3（#150）: 飛行機は、駐機場から出発したあと、向きを変えるまで反転して走る。編成内の車両の順序は変えず、反転の状態だけを変える。先頭の車両が変わらないので、安定して飛べる。連結して 1 枚の絵を描く車両アドオンでは問題になる可能性がある。
- v51（#319）: 飛行高度を、本家準拠の固定の高さ 3 と、KUTA 準拠の速度に応じた高さで切り替えられる。設定は「高高度の飛行を許可」（`allow_higher_flight`、既定は ON）。ON のとき高度は「最高速度（km/h）÷ 33」（最小 5、最大 30）で、着陸までの距離は高度 − 2。OFF のとき高度は 3 で、着陸までの距離も 3。この設定はセーブデータに保存され、v51 より前のセーブは ON として読む。
