# 仕様の補足

[OTRP wiki](https://github.com/teamhimeh/simutrans/wiki/OTRP-Home) に書かれていない挙動や、ソースを読んで確かめた細かい仕様を置きます。

wiki に同じ主題のページがあるときは、冒頭でそのページへリンクし、ここには差分だけを書きます。

ページの足し方は[書き方](../contributing.md)を見てください。

PR とリリースノートから拾ったページは、OTRP v63_4 のソースコードと照らし合わせてあります（2026-11-21）。ゲームを動かしての確認はしていません。コードで決められなかった項目には「コードでは確かめていない。」と書いてあります。ゲームで確かめたら、そのページに確かめた場所と日付を足してください。
