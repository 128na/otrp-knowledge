# ツール・ショートカット・画面

> この内容は、OTRP の PR とリリースノートの記述から拾ったものです（2026-11-14 時点）。ゲームの動作やソースコードでは確かめていません。仕様は [OTRP wiki](https://github.com/teamhimeh/simutrans/wiki/OTRP-Home) が正です。

ツールの修飾キー（shift・ctrl）、ツール番号、`menuconf.tab` とキーバインド、各ウィンドウに足された小さな機能、クリップボードへのコピー機能をまとめる。

## ツールの修飾キー

### 撤去系ツールの範囲・ルート撤去

- 撤去ツールの範囲選択は 2019 年に箱形（3D）の範囲へ拡張された。範囲内の撤去できる全オブジェクトを消す。複数マスでエラーが出たときは、最初のエラーだけをダイアログに出す方針（2019 年時点の OTRP の挙動）。
- 撤去ツールのクリック順は、橋脚、信号、送電線、（駅、架線、線路など）の順に変わった。同じタイルを繰り返しクリックすると、この順に 1 種類ずつ消える。以前は「送電線、信号、（駅、架線、線路など）、橋脚」の順だった。
- 橋脚だけを消す専用ツールがある（リリースの番号は `general_tool[56]`）。
  - shift で複数段の橋脚、shift+ctrl で範囲内の橋脚をまとめて消す。
  - 所有者が違う橋脚は消せない（公共事業プレイヤーは可）。橋脚の無いタイルでは何もしない。
- 駅撤去ツールは複数の高さをまとめて撤去できる。範囲撤去は ctrl 押下時に限られる。ctrl なしではルート上の駅を撤去する（PR の記述）。リリースノートには「ルート撤去は shift 押下時」とあり、PR と食い違う。他社の駅は消えない。
- 信号撤去ツールは、ctrl なしでルート上の信号をまとめて、ctrl 押下で範囲内の信号を撤去する。複数の高さをまとめて消せる。
- トンネル入口に併用軌道（tram）があるとき、入口で撤去ツールを使うと、トンネル全体ではなく軌道だけが消える。
- 出典: [#23](https://github.com/teamhimeh/simutrans/pull/23)（2019-05-12 マージ）、[#617](https://github.com/teamhimeh/simutrans/pull/617)（2026-07-11 マージ）、[#630](https://github.com/teamhimeh/simutrans/pull/630)（2026-06-30 マージ）、[#629](https://github.com/teamhimeh/simutrans/pull/629)（2026-06-29 マージ）、[#337](https://github.com/teamhimeh/simutrans/pull/337)（2026-02-06 マージ）、リリース v51_1、v55_10、v57_0_1
- 関連する wiki: [OTRP-Home](https://github.com/teamhimeh/simutrans/wiki/OTRP-Home)（範囲撤去の shift / shift+ctrl は記載あり。上記の追加分は記載なし）、[ツール定義](https://github.com/teamhimeh/simutrans/wiki/%E3%83%84%E3%83%BC%E3%83%AB%E5%AE%9A%E7%BE%A9)（`general_tool[56]` は名前のみ）

### 土地・斜面ツールの範囲操作

- 土地を 1 段上げ下げするツール（v50_3 以降）:
  - shift を押しながら使うと、現在の高さから 1 段上げ下げする。
  - shift を押しながらドラッグすると、ドラッグした線上に、現在の地形を活かした尾根・谷ができる。
  - shift と ctrl を同時に押して範囲で使うと、範囲全体を元の高さから 1 段上げ下げする。
- 人工斜面ツールは範囲でも使える（v58_0_2）。
  - クリック: 1 タイルに適用。
  - ドラッグ: 通過した各タイルに 1 回ずつ適用。
  - ctrl+ドラッグ: 始点と終点を対角とする矩形をマーカーでプレビューし、ボタンを離したときに全体へ適用。
  - 地表から始めた範囲操作は各座標の地表が対象。トンネルや高架など地表以外から始めた場合は、始点と同じ高さのレイヤーが対象。
  - 変更できないタイルを含んでもスキップして残りを処理し、エラーを通知する。
- 出典: [#291](https://github.com/teamhimeh/simutrans/pull/291)（2026-01-18 マージ）、[#662](https://github.com/teamhimeh/simutrans/pull/662)（2026-07-15 マージ）、リリース v50_3、v58_0_2
- 関連する wiki: [OTRP-Home](https://github.com/teamhimeh/simutrans/wiki/OTRP-Home)（ctrl で範囲が始点と同じ高度になる、のみ）

### way・駅の建設時の修飾キー

- ctrl を押して way を敷設すると、同じタイルを 2 回クリックして 1 マスだけの way を作れる（通常は作られない）。何もない平地・坂には孤立した way ができ、既存の way があるタイルでは 1 マスだけ置き換える。`oneway` / `halt_mode` のときは既存の `ribi` を保存する。既存の道路には 1 マスの踏切も置ける。既存の道路が斜め・終端・分岐のときは踏切を置けない。（v58_0_2）
- shift を押しながら駅を設置すると、隣に駅があっても新しい駅として設置する（既存駅を上書きするときは新駅にならない）。shift+ctrl を同時に押すと、新しい駅を 1 つ作り、既存の駅が無いタイルはすべてその駅として建てる（離れた線路にも同じ駅を建てられる）。同じ駅かどうかの判定は、近くに複数の駅があるとき同じ高さのタイルを優先して調べるよう直された。（v55_6_1）
- 出典: [#660](https://github.com/teamhimeh/simutrans/pull/660)（2026-07-17 マージ）、[#553](https://github.com/teamhimeh/simutrans/pull/553)（2026-06-04 マージ）、リリース v58_0_2、v55_6_1
- 関連する wiki: 記載なし

### 公共化・私有化ツール

- ctrl を押しながら公共化すると、way・信号などのチェックを省略する（駅しか公共化しないため）。駅の建物の所有者は変わらず、駅を別の駅アドオンで上書きしても所有者は変わらない。
- 公共化できない条件になる標識は「自家用車進入禁止・他社進入禁止」の標識だけ。振り分け禁止・一方通行の標識があっても公共化できる。
- 公共駅や他社駅を自社化したとき、所有者の異なる駅を統合したときは、他社乗り入れが自動で許可される（従来乗り入れていた他社の路線が一時的につながらなくなるのを防ぐ）。
- 公共駅を私有化するとき（v62_0_3）:
  - ctrl なし: 公共駅タイル内の公共物の軌道なども私有化する。
  - ctrl あり: 駅建物の所有は元のままで、軌道も私有化しない。
  - 公共駅内にある別会社の私有軌道は、このツールでは私有化されない。
- 出典: [#389](https://github.com/teamhimeh/simutrans/pull/389)（2026-02-18 マージ）、[#386](https://github.com/teamhimeh/simutrans/pull/386)（2026-02-22 マージ）、リリース v52、v62_0_3
- 関連する wiki: [OTRP-Home](https://github.com/teamhimeh/simutrans/wiki/OTRP-Home)（shift / ctrl の概要のみ）
- **wiki との違い:** wiki は shift を「現在有効なプレイヤー所属の停留所になる」、ctrl を「駅設備を元のプレイヤー所有のまま公共化」と書くだけ。v62_0_3 で、ctrl なしの私有化は公共駅タイル内の軌道まで私有化する、と分かる（wiki に記載なし）。

### ピペット（スポイト）ツール

- `general_tool[51]`。本家のピペットを移植したもので、v50_3 で追加された。木と地表オブジェクトも抽出して設置できる。ネットワークゲームでも動作が確認されている。
- 既定では一番上にあるアドオン（線路の上の架線・信号・駅など）を取る。そのため電化路線では線路そのものを取れない。
- 修飾キー:
  - ctrl: 一番下のオブジェクト（way など）を取る（v50_3_1）。
  - shift: `weg_nr(1)` とその wayobj を対象にする（併用軌道や踏切で併用軌道・線路を取る）（v51_2）。
  - shift+ctrl: `weg_nr(1)` のみ。
- 他社の way や物をピペットすると、操作する会社がその会社に切り替わる（v52）。追い越し車線設定などのフラグも取れる（v55_8。対象フラグの一覧は PR に無い）。
- 出典: [#298](https://github.com/teamhimeh/simutrans/pull/298)（2026-01-18 マージ）、[#303](https://github.com/teamhimeh/simutrans/pull/303)（2026-01-18 マージ）、[#360](https://github.com/teamhimeh/simutrans/pull/360)（2026-02-11 マージ）、[#382](https://github.com/teamhimeh/simutrans/pull/382)（2026-02-18 マージ）、[#596](https://github.com/teamhimeh/simutrans/pull/596)（2026-06-16 マージ）
- 関連する wiki: [ツール定義](https://github.com/teamhimeh/simutrans/wiki/%E3%83%84%E3%83%BC%E3%83%AB%E5%AE%9A%E7%BE%A9)（`general_tool[51]` の名前のみ。修飾キーは記載なし）

### 停車駅移動ツール（スケジュール上の停車位置の移動）

- PR は `tool_stop_mover_t` を「Replace Stop（スケジュール移動）」ツールと呼び、スケジュール内の停車位置を移動するツールとして説明している。リリースノートは `general_tool[31]` を「停車駅移動ツール」と書く。
- 他社乗り入れを許可した駅で、自社のスケジュールに使えるようになった（v44_2。v50_5 でその挙動を修正）。
- ctrl を押しながら移動すると、そのマスのスケジュールだけを移動する（同じホームの別のマスのスケジュールは動かさない）（v46）。ctrl なしのとき、同じホームの別タイルに停車する別スケジュールをまとめて移動するかを選べる。
- 斜めタイルの駅でも動く。斜めタイルでループ状のホームが始点に戻ると無限ループになる問題は直った。
- 2 タイル以上のホームで、クリックしたタイルとスケジュール登録のタイルが違うと移動されない不具合があった（端のタイルの走査漏れ）。隣り合う別の停車場のタイルが混ざる問題とあわせて 2026-05-27 に修正された。水路と空路は別の処理で影響なし。
- 出典: [#77](https://github.com/teamhimeh/simutrans/pull/77)（2025-03-23 マージ）、[#170](https://github.com/teamhimeh/simutrans/pull/170)（2025-09-23 マージ）、[#173](https://github.com/teamhimeh/simutrans/pull/173)（2025-09-24 マージ）、[#538](https://github.com/teamhimeh/simutrans/pull/538)（2026-05-27 マージ）、リリース v44_2、v46、v50_5
- 関連する wiki: [ツール定義](https://github.com/teamhimeh/simutrans/wiki/%E3%83%84%E3%83%BC%E3%83%AB%E5%AE%9A%E7%BE%A9)（`general_tool[31]` を「乗り物を停止させる」と記載）
- **wiki との違い:** wiki の説明は「乗り物を停止させる」だが、PR とリリースノートではスケジュールの停車位置を移動するツールとして扱われている。`tool_stop_mover_t` と `general_tool[31]` が同じものであることは PR には明記がない（リリースノート v44_2 が `stop_mover_t` の PR を `general_tool[31]` と書いている点から対応していると読める）。

## menuconf.tab とキーバインド

### ゲーム内のキーバインド設定（Keybindings タブ）

- 表示設定ウィンドウに「Keybindings」タブが付き、ゲーム内でキー割り当てを変えられる（v62_4_1。ただし v62_4_1 にはバグがあり v62_4_2 が案内されている）。
- 「Change keybind」を押してキーを入力すると、その操作のキー欄だけを pakset の `config/menuconf.tab` に保存し、その場で反映する。コメント・改行・アイコン・効果音・ツールのパラメータは保持される。ctrl・shift との組み合わせに対応。Esc、タブ切り替え、ウィンドウのフォーカス喪失で入力待ちをキャンセルする。
- 初期値の扱い:
  - Keybindings タブを初めて開いた時点の `menuconf.tab` が、同じフォルダの `menuconf.default.tab` に退避される（既存の退避ファイルは上書きしない）。
  - 「初期設定に戻す」は、この退避ファイルを使う。初期値は pakset 出荷時の値ではなく、初回表示時の値になる。
- タブを開くたびに `menuconf.tab` のキー設定を読み直す。起動中の外部編集も反映される。メニュー構成・ツールの追加・並べ替え・パラメータの変更は再起動が必要。
- 競合するキーを入力すると、キーと割り当て済みの操作名と解消方法を警告し、設定は変えない。ゲーム固定の操作に使うキーの一部は割り当てられない。
- 保存の表記は `]`、`^A`、`+A`、`F15`、`SPACE`、`COMMA` など。解除は空欄。正確に再読み込みできない組み合わせだけ数値表記になる。既存の数値表記も読める。pakset の config フォルダへの書き込み権限が必要。
- `menuconf.tab` のキーにスペースを `SPACE` と書けるようになったのは v51_2。
- 出典: [#766](https://github.com/teamhimeh/simutrans/pull/766)（2026-10-22 マージ）、リリース v51_2、v62_4_1
- 関連する wiki: [ツール定義](https://github.com/teamhimeh/simutrans/wiki/%E3%83%84%E3%83%BC%E3%83%AB%E5%AE%9A%E7%BE%A9)（ミニマップ出力の節に特殊キー名の書式がある。ゲーム内編集は記載なし）

### ツールバーのスクロールバーと icon_height

- アイコンの数が表示範囲を超えると、スクロールバーが付く（メインメニューバーは下に左右へ、それ以外は右端に上下へスクロール）。ドラッグとマウスホイールに対応（v60_0_1）。
- アイコンの描画サイズは `menuconf.tab` の `icon_height` で指定する。既定は 32。0 にするとアイコンを表示しないモードになる。64 より大きいと、アイコンが正しく描画されないことがある。
- メニューバーの位置（高度な設定の `menubar_position`）に合わせてスクロールバーの位置も変わる。

### 車両のツールチップ

`simple_tool[20]`（乗り物のツールチップ表示）の状態表示モードに、次のものが足された。

- 路線名と車両の状態を同時に表示するモード（`env_t::show_vehicle_states` の 4 番目の状態、v44_2）。`simple_tool[20]` で切り替えたときにこのモードに入らない不具合は修正された（モードは後に enum になった）。
- 子編成が積むまで待機しているときは、子編成の積載量も表示する。
- ツールチップに路線色（v51_1）と乗車率のバー（v51_1）を出せる。バーは全積載量をグレー、乗車率 100% 以下を緑（相対的な乗車率）、100% 超をオレンジの状態表示で示し、バーは伸びない。路線色と乗車率はそれぞれオン・オフできる（v52）。
- 自社の編成のツールチップだけを表示する `simple_tool[51]` がある（v53。wiki のツール表に番号あり）。

## 路線・スケジュール・車庫のウィンドウ

### 路線ウィンドウと路線一覧

- 路線にメモを付けられる（路線ウィンドウの入力欄、v50）。他社の路線の編集は禁止された（公共事業プレイヤーは除く）。路線メモは路線一覧のフィルターにも使える（「メモをフィルターに使用」ボタン、v60_0_1）。
- 路線ごとのラインカラー:
  - 路線名・編成名のツールチップに出る（v51_1）。
  - スケジュールウィンドウの路線名の表示色に反映される（v54_0_1）。
  - 色の選択肢が 28 色増えて計 56 色になった（v53）。
  - 路線のラインカラーを車両の塗装に使える。プレイヤーカラー 1 にあたる部分の色を置き換える（v55_2_1）。
  - プレイヤーカラー設定ウィンドウの `Change line color as current player color` ボタンで、自社の全路線のラインカラーを現在の会社色（主色）に変える（v55_10）。他社の路線は変わらない。
- 路線一覧の右上のグラフに、11 番目の曲線「Avg. density」（紫）が足された（v55_7）。値は `Freight ton-kilo ÷ 走行距離` で、表示のたびに計算し、セーブしない。
- 路線一覧から路線を開くと、その路線の全編成の位置が地図上に出る。

### スケジュールウィンドウのボタン

- 各エントリとスケジュール詳細に上下ボタンがあり、削除して挿入し直さなくても順番を変えられる（2026-02-06 マージ）。
- ctrl を押しながらスケジュールウィンドウを開くと、すべての詳細設定を開いた状態で開く（v51_2）。
- 「先頭へ」ボタン: 押した状態でエントリをクリックすると、そのエントリが先頭になるよう並べ替える（A→B→C→D で C を選ぶと C→D→A→B）。並べ替えのあとも押した状態が続くため、別のエントリをクリックすると再び並べ替えが起きる（レビューで指摘された挙動で、仕様として残ったかは PR から読み取れない）。
- 削除モードのとき、マウスホイールでエントリが消えないようにした。
- 出典: [#350](https://github.com/teamhimeh/simutrans/pull/350)（2026-02-06 マージ）、[#364](https://github.com/teamhimeh/simutrans/pull/364)（2026-02-11 マージ）、[#749](https://github.com/teamhimeh/simutrans/pull/749)（2026-10-12 マージ）、[#88](https://github.com/teamhimeh/simutrans/pull/88)（2025-04-15 マージ）

### 車庫ウィンドウ

- 全車両をしまうボタン、解結ボタンがある（v51_1）。
- ctrl を押しながら押すボタン:
  - 「編成をコピー」: 現在の編成をクリップボードにコピーする。
  - 「編成を貼り付け」: 現在の編成の後ろに貼り付ける。
  - 売却・全車両除去: 車庫内の全編成に適用する（v51_2）。
- ctrl+「編成をコピー」は、ゲーム内のクリップボードに加えて OS のクリップボードへ `vehicle[0]=<車両名>` の形式で車両一覧も入れる。編成名は含まれない。編成詳細ウィンドウの「編成をコピー」も、ctrl 併用で同じ書式になる（v55_6_1）。
- 車庫内の全車両を売却するボタンがある。「車庫内総車両数表示」の隣にあり、編成として組まれた車両は売却されない。
- 車両名の検索欄の入力値は保存され、フィルターは車庫ごとに保持される。
- 鉄道車庫で路面電車の編成をコピーできない不具合は直った（v63_1_2）。

## 一覧・記録・コピー機能

### クリップボードへのコピー（CSV 的に使える形式）

- 都市一覧の「Copy city list」ボタン: 都市名と人口をタブ区切りでコピーする。先頭行は見出し、以降は `都市名<TAB>人口` の 1 行ずつ。成長量は含まない。表計算ソフトに貼れる（v41_1）。
- 路線ウィンドウのボタン: 路線の各停留所のデータをタブ区切りでコピーする。列は停留所名と、駅一覧の並び替え種別ごとの貨物情報のラベル（複数列）。見出しは翻訳に依存しない内部名（v51）。
- 未使用アドオンの一覧: 現在のマップで使っていないアドオンの一覧を表示するボタンがある。一覧はロード完了時に表示され、アドオン名と属性を CSV としてコピーできる（v52_1）。
- news / error メッセージは、fatal 以外もコピーできる（v55_9）。
