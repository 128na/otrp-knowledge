# PR 由来のページを OTRP v63_4 のソースと照らし合わせた記録（2026-11-21）

PR とリリースノートの文章だけから書いたページを、OTRP v63_4 のソースコードと照らし合わせ、合わない記述を直した。
この記録はその時点で確かめたことで、書いたら変えない。

## 1. やり方

- 対象: OTRP v63_4（2026-11-20 公開）のソースコード。ゲームは動かしていない。
- ページの項目（`###`）ごとに、書いてある事実をソースで確かめ、「合う」「訂正」「確かめられない」の 3 つに分けた。
  - 合う: 本文を変えない。
  - 訂正: 本文を今の動きに書き直す（訂正の注記は付けない）。
  - 確かめられない: 画面の見た目、実行時の振る舞いが込み入っているもの、どの版で入ったかの経緯など。項目に「コードでは確かめていない。」を足した。
- 設定のキー名、既定値、ボタンの表示名は、ソースで分かったものを埋めた。表示名はゲームに入っている日本語訳から取った。
- 「v52 で入った」のような経緯は、コードでは確かめられないので、リリースノート由来のまま残した。
- 「訂正」と判定した項目は、別の作業者がもう一度ソースで読み直し、誤りと言い過ぎを直した。
- 「wiki との違い」は、2026-11-21 時点の wiki と比べ直し、[wiki との違いの一覧](../spec/wiki-diff.md) を作り直した。

## 3. 分かったこと

- PR の本文やリリースノートの書き方と、今のコードの動きが違うものが多い。PR の後の変更で動きが変わったものと、PR の説明そのものが実装と違うものがある。
- 「原文からは分からない」としていた設定のキー名・既定値・ボタン名の多くは、ソースと日本語訳から埋められた。
- アドオンの dat に書くキー名のうち、本体は読めるが同梱の makeobj に書き出す処理が無いものは、ソースだけでは決められなかった。

- 画面の見た目（色、ボタンの日本語名がどちらの訳ファイルから出るか）。
- 込み入った実行時の動き（停車フラグ P の細部、長い車両の在線確認、併用軌道の敷設条件、way の 1 マス敷設の置き換え）。
