# 分岐（switch・ex）の絵の今の振る舞い：way の種類ごとの表と道路のくせ（2026-11-20）

way の T字・十字の「分岐の絵」が、way の種類ごとにどう選ばれるかを、本体のソースで確かめた記録。仕様を整理し直す前の状態を残す。書いたら変えない。

- 対象: OTRP `OTRP-KUTAv6`（`1cc2e78b9` の時点の既定ブランチ）と、固定の道具の `feature/switch-image-override`（`964fc7f0b`）。本家は `simutrans/simutrans` の `master`（2026-11-20 に GitHub で読んだ）。
- 断りの無いものは、ソースを読んで確かめたもの。ゲームで確かめたものは、そう書く。
- 固定の道具の作りは [開発 / 分岐（switch）の絵の固定](../dev/switch-image-override.md)、dat のキーと絵の作り方はアドオン開発リポジトリの way 系リファレンスの「分岐（switch）の絵」にある。ここでは重ねて書かない。

## 1. 絵の番号

way の絵は、奥・手前・季節ごとに 1 本のリストで、番号で引く（`descriptor/way_desc.h`）。

| 番号 | 中身 | 引き方 |
|---|---|---|
| 0〜15 | 通常の絵 | ribi そのもの |
| 16〜20 | switch、`nw` = false（dat の `nse1` `new1` `nsw1` `sew1` `nsew1`） | `16 + ribi_to_extra[ribi]` |
| 21〜25 | switch、`nw` = true（dat の `nse2` 〜 `nsew2`） | `21 + ribi_to_extra[ribi]` |
| 26〜30 | ex、`nw` = false | `26 + ribi_to_extra[ribi]` |
| 31〜35 | ex、`nw` = true | `31 + ribi_to_extra[ribi]` |

- `ribi_to_extra` は `nse` → 0、`new` → 1、`nsw` → 2、`sew` → 3、`nsew` → 4。
- 有る無しは枚数だけで決まる。16 枚を超えると switch あり、26 枚を超えると ex あり（`descriptor/reader/way_reader.cc`）。waytype は見ない。
- makeobj（本家と同じ 60.12）が書けるのは 25 番まで。ex の 26〜35 番を書ける makeobj は公開されていない。
- `nw` の意味は絶対方位に結び付いている。T字の 8 通りの絵を画面で見ると（アドオン開発リポジトリの対応表）、`nw` = true（「2」）は北–西・南–東のカーブ（画面の上と下の角を通る）、`nw` = false（「1」）は北–東・南–西のカーブ（画面の右と左の角を通る）。列車の予約も、曲がる経路が南東・北西の角を通るとき `nw` = true にする（`schiene_t::reserve`）。本家の予約（`ribi_type(前, 次)` が北東・南西のとき true）も同じ経路を同じ絵にする。

## 2. way の種類ごとの振る舞い

絵を選ぶ道は 3 つある。

- **隣を見る自動選択**: `weg_t::calc_image` の 730〜740 行。`get_waytype()` が `track_wt` なら `select_switch_image`、`road_wt` なら `select_switch_road_image`。
- **予約での切り替え**: `schiene_t::reserve`（161 行）。新しく予約した列車の経路が、T字・十字のタイルで曲がるとき、switch の絵に替える。`schiene_t` の派生（`monorail_t`・`maglev_t`・`narrowgauge_t`・`runway_t`）にも効く。tram は `get_finance_waytype() != tram_wt` で外れる。ex の絵のタイル（`get_is_ex_image()`）も外れる。
- **固定の道具**（`feature/switch-image-override` だけ）: `apply_switch_image_override`。`calc_image` の最後で、waytype を問わずに上書きする。予約での切り替えは、固定したタイルでは働かない。

tram は dat の `waytype=tram_track` を読むときに `track_wt` に直される（`way_reader.cc`。`styp` が `type_tram` になる）。このため、隣を見る自動選択では線路と同じに扱われる。隣のタイルも `track_wt` で探すので、線路と tram は区別しない。

| 種類 | 隣を見る自動選択 | 予約での切り替え | 固定の道具 | 実機での確認 |
|---|---|---|---|---|
| 線路（`track_wt`） | あり（線路の決まり。3 章） | あり（T字と十字。16〜25 番） | あり（標準・1・2・ex 3・4） | 自動の T字 8 通りと ex の形はゲームで確かめた（2026-11-14、アドオン開発リポジトリの 9.2・9.4） |
| 路面電車（tram） | あり（線路と同じ決まり） | なし | あり | 固定の道具は OTRP 本体の作者が確かめた。自動選択は未確認 |
| 道路（`road_wt`） | あり（道路の決まり。4 章） | なし | あり | 自動の十字はゲームで確かめた（AMI の見本、2026-11-19）。ex の自動選択は未確認 |
| モノレール | なし | あり | あり | 固定の道具は OTRP 本体の作者が確かめた。予約での切り替えは未確認 |
| リニア | なし | あり | あり | 同上 |
| ナローゲージ | なし | あり | あり | 固定・予約とも未確認 |
| 運河（`water_wt`、`kanal_t`） | なし | なし（`schiene_t` でない） | あり | 固定の道具は単色の検証用アドオンで確かめた |
| （参考）空路（`runway_t`） | なし | コード上はあり（`schiene_t` の派生）。誘導路・滑走路で働くかは未確認 | あり | 固定の道具は確かめた。滑走路は T字を作れない |

共通の条件:

- **斜めの除外**: 自動選択は `!is_diagonal() && !is_close_diagonal()` のときだけ働く。斜めの印はカーブにしか付かないので、T字・十字で効くのは、近い斜め（十字のタイルが 2 本の斜めになっているもの）だけ。予約での切り替えには斜めの条件が無い。固定の道具は、T字・十字で、斜め・近い斜めでないタイルだけ（`is_switch_junction`）。
- **ビルドの条件**: 自動選択は `#if COLOUR_DEPTH != 0 && MULTI_THREAD != 0` の中にある。`COLOUR_DEPTH` は `BACKEND = posix`（画面なしのサーバー）で 0。`MULTI_THREAD` は Makefile では `MULTI_THREAD = 1` のときだけ定義され、CMake ではスレッドが使えないと無効になる。どちらかが 0 のビルドでは、自動選択が丸ごと無くなる。予約での切り替えと固定の道具は、この条件の外にある。配布用の CI（`.github/build*.sh`）は `MULTI_THREAD = 1`。このビルドの違いはゲームでは確かめていない。`MULTI_THREAD` で分けた理由は分からない（KUTA_v6 の 1 コミットで入った。`53ca75e21`、2021-12-12）。
- **季節の切り替え**: `weg_t::check_season` は、今の絵を自分の ribi の switch の絵（`nw` の 2 通り）とだけ比べて、雪の絵に替える。ex の絵と、道路の十字が借りた T字の絵（4 章）は、どちらにも当たらないので標準の絵に戻る、と読める。次に `calc_image` が走れば戻る。ゲームでは確かめていない。固定の道具は `check_season` の最初で上書きするので、この影響を受けない。
- **マップの回転**: `weg_t::rotate90` は ribi を回すが、固定の値（`switch_image_override`）は回さない。`nw` は絶対方位に結び付いているので（1 章）、T字の `nse2`（南–東のカーブ）を 90 度回すと、同じ値は `sew2`（東–南）を指す。本来の向きは `sew1`（西–南）なので、固定した T字はマップを回すとカーブが逆になる、と読める。十字の 1・2 も、画面の左右・上下が入れ替わるので同じ。ゲームでは確かめていない。近い斜め（`close_diagonal_state`）は回転で `^= 3` している。本家の `switch_state` も回転で回さない（次の予約で直る）。

## 3. 線路（tram を含む）の自動選択

`select_switch_image`。ex の絵を使う形は、way が ex の絵を持つときだけ。

| タイル | 条件 | 出る絵 |
|---|---|---|
| T字 `nse`（枝が東） | 東隣が北–西のカーブ | `nse2`（21） |
| | 東隣が南–西のカーブ | `nse1`（16） |
| | 東隣が向かい合う T字（`nsw`）で、両方の本線の隣が渡り線の形 | `nse2` か `nse1`（4 タイルの向きで決まる） |
| | 上のどれでもなく、北隣と南隣がそろって西へ曲がる（Y字） | ex `nse`、`nw` = false（26） |
| T字 `nsw`・`new`・`sew` | `nse` を回した同じ決まり | `nsw` は 23・18・28、`new` は 22・17・27、`sew` は 24・19・29 |
| 十字 | 北隣と南隣（または東隣と西隣）が、そろって同じ側へ曲がる（三方分岐） | ex の T字の枠、`nw` = true。1 本の側が東なら `nse` の 31、北なら `new` の 32、西なら `nsw` の 33、南なら `sew` の 34 |
| 十字 | 東隣が西–北のカーブで、向きの制限で西だけ。北隣は北へ、西隣の南隣は南か西へつながる（渡り線） | 十字に ex `sew`、`nw` = false（29）。西隣に switch、`nw` = false |
| 十字 | 上のどれでもない | 標準の十字。十字の switch（20・25）は自動では出ない。予約では出る |

- 三方分岐と渡り線は、十字のタイルに T字の枠の絵を出す。十字の ex の枠（30・35）は線路では使われない。
- 29 番は、T字 `sew` の Y字と、十字の渡り線の両方に使われる。1 枚の絵で両方は描けない。
- 渡り線は、東隣が西–北のときだけ。左右反対の形はコメントアウトされている。どういう線路の形を描く絵なのか（片渡り線か両渡り線か）は、コードからは分からない。
- 絵が空のときの扱いは無い。枚数が 16 を超える way は、予約や自動選択で 16〜25 番を引き、そこが空なら空の絵を描く（`get_switch_image_id` は空でも番号の絵を返す）。ex も同じ。
- 予約での切り替えは T字と十字の両方に働く。十字では 20・25 番が出る。

## 4. 道路の自動選択と、そのくせ

`select_switch_road_image`。

### 4.1 決まり

| タイル | 条件 | 出る絵 |
|---|---|---|
| T字 `nse`（枝が東） | 東隣が T字か十字で、北隣・南隣がどちらも T字・十字でない | `nse1`（16） |
| | ex があり、北隣だけが T字・十字 | ex `nse`、`nw` = true（31） |
| | ex があり、南隣だけが T字・十字 | ex `nse`、`nw` = false（26） |
| T字 `nsw`（枝が西） | 西隣が T字か十字で、本線の隣がどちらも T字・十字でない → `nsw1`（18）。ex があり、南隣だけ → 33（true）、北隣だけ → 28（false） | 左のとおり |
| T字 `new`（枝が北） | 北隣が T字か十字で、本線の隣がどちらも違う → `new1`（17）。ex があり、東隣だけ → 32（true）、西隣だけ → 27（false） | 左のとおり |
| T字 `sew`（枝が南） | 南隣が T字か十字で、本線の隣がどちらも違う → `sew1`（19）。ex があり、西隣だけ → 34（true）、東隣だけ → 29（false） | 左のとおり |
| 十字（ex なし） | 隣が T字か十字。東 → 西 → 北 → 南の順に見て、最初に見つけた向き | 東なら `nse2`（21）、西なら `nsw2`（23）、北なら `new2`（22）、南なら `sew2`（24） |
| 十字（ex あり） | 東隣が T字・十字のとき、南隣だけも → `nsew2`（25）、北隣だけも → `nsew1`（20）、ほか → `nse2`（21）。東でなく西隣のとき、北隣だけも → ex 十字 true（35）、南隣だけも → ex 十字 false（30）、ほか → `nsw2`（23）。東西でなく北隣だけ → `new2`（22）、南隣だけ → `sew2`（24） | 左のとおり |

「T字・十字」の判定は `ribi_t::is_threeway`（十字も含む）。T字の ex の `nw` の真偽と本線の隣の向きの対応は、4 つの T字で回転の関係になっていない（`nse` を 90 度回すと `sew` だが、true になる側は北 → 東ではなく西）。

### 4.2 くせ

- **「1」は、枝の先が分岐になっている T字に出る。** 2 本の道路を隣り合わせに並べて、渡り口でつないだ形が当たる。線路の「1」（枝が隣でどちらへ曲がるか）とは意味が違う。
- **「2」は十字のタイルにしか出ない。T字には自動では出ない。** 十字のタイルに、T字の枠（`nse2` など）の絵を借りて出す。つまり T字の「2」の 4 枚は、道路では「多車線の十字の 1 タイル」の絵として使われる。
- **十字の向きの選び方が偏る。** 東 → 西 → 北 → 南の順に最初の 1 つだけを見るので、3 本以上並べた交差点や、南北・東西とも並べた交差点では、どの十字もほぼ `nse2`・`nsw2` になる（AMI の見本で 2×4〜6×6 の 8 通りを敷いて確かめた。6×6 はどの行も `nse2 nse2 nsw2`。`OTRPv64_3.exe`、2026-11-19）。
- **固定の道具と衝突する。** 固定の道具で dat の「2」を選ぶと、T字のタイルに T字の「2」の絵が出る。T字の形に描くと、自動の十字の 4 本目の腕が閉じて見え、十字の形に描くと、固定した T字が十字に見える。1 枚の絵で両方は満たせない（AMI の道路、2026-11-19）。ex の絵を足しても、十字の行き先が ex に移るのは東か西の隣が分岐のときの一部だけで、依頼元の作業では 4×4 だけが直ったと報告された（この記録では再現していない）。4.1 の表から読むと、ex があれば 2×2 の十字の 4 隅は 25・20・30・35 番（北西・南西・北東・南東）に分かれる。3×3 では、北と南の両方に隣がある真ん中の行が、T字の枠（`nse2`・`nsw2`）に戻る。
- **由来**: 自動選択は KUTA_v6 の 1 コミット（`53ca75e21`）で入った。細かい履歴は公開されていない。道路の多車線の交差点のために、線路の分岐の枠を流用した作りと読める。

## 5. 本家（std）の今の作り

`simutrans/simutrans` の `master`（`src/simutrans/obj/way/`）。

- 分岐の絵は 16〜25 番だけ。ex は無い。makeobj のキーも `nsew2` まで。
- 隣を見る自動選択は無い。列車の予約で、経路が曲がるときだけ switch の絵にする（`schiene_t::reserve`）。tram も外していない。
- 2026-06 に、状態を `weg_t::switch_state`（0 = 未定、1・2）として持つようになった（`0bc3f449d`、2026-06-16。分岐はまず未定の絵を出す、という変更）。未定の間は標準の絵（無ければ 1）。季節の切り替え・`calc_image` はこの状態で描き直す。保存はしない。
- `calc_image` は T字・十字を `switch_state` で描く。道路は予約されないので 0 のままで、標準の絵になる。`check_season` は道路を外している。つまり本家では、道路の 16〜25 番は使われない。
- `rotate90` は `switch_state` を回さない（近い斜めの状態は回す）。

## 6. 分岐の絵を持つ既存の dat

参照用に手元にある dat で、コメントでない `image[new2]` を持つものを数えた（2026-11-20）。

| waytype | 数 | 出どころ |
|---|---|---|
| track | 74 | pak128（`rail_tracks`・`rail_elevated`）、iss、SIS の新幹線、AMI、blender-poc |
| maglev_track | 8 | iss |
| monorail_track | 6 | iss |
| tram_track | 4 | iss、AMI（橋脚） |
| narrowgauge_track | 2 | iss |
| road | 0 | SIS の道路は `Image[NSE1]` などを書いているが、全部コメントアウトされている |

- 数は dat の数で、iss はソースと配布用のコピーの両方を数えている（重複を含む）。
- 道路で分岐の絵を使う既存の dat は見つからなかった。AMI の道路も、仕様が決まるまで分岐の絵を外す作業をしている（この時点では手元の作業で、公開されていない）。
- ex の絵（26〜35 番）を持つ dat は無い（書ける makeobj が無い）。

## 7. 整理するときの論点

仕様の案は `128na/simutrans` の issue にまとめる予定（この時点では起票していない）。この時点で見えた論点:

- 番号が「タイルの ribi」で引かれるのに、自動選択は別の ribi の枠を借りる（道路の十字が T字の枠、線路の三方分岐・渡り線が T字の ex の枠）。借りた枠は、固定の道具・季節の切り替えと衝突する。
- 「1」「2」の意味が、線路（分岐器の向き。絶対方位）と道路（多車線の交差点の位置）で違う。固定の道具の名前は線路の意味で付いている。
- 29 番が Y字と渡り線で二重に使われている。
- 回転で固定の値が逆の絵を指す。
- 自動選択が `track_wt` と `road_wt` だけで、ナローゲージ・モノレール・リニアは予約だけ。ビルドの条件で自動選択が消える。
- 本家との互換で動かせないのは 0〜25 番の線路の意味（予約で出す絵）。道路の 16〜25 番は本家では使われない。26 番以降は本家が読まない。
