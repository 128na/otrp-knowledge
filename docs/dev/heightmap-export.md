# PNG 高さマップ（地形データ）出力の知見

> 対象は fork の [128na/simutrans](https://github.com/128na/simutrans) の `OTRP-KUTAv6` ブランチに足した機能。本家 OTRP（teamhimeh/simutrans）には無い。

PNG 高さマップ出力で分かった、読み込み処理の決まりと、出力の限界・テストの保証範囲。文中の `simutrans/` はリポジトリのルートを指す。
GitHub issue `128na/simutrans#3`（開発メモ）の内容をここへ移した（2026-11-14）。その時点の検証結果は
[記録](../records/2026-10-23_png-heightmap-export.md)にある。

- 実行手順（検証ガイド）: `simutrans/tests/heightmap-export.md`
- 実装のコミット: `128na/simutrans` の `7bc836f48d9d539801de8df696ea0fda9486a5a1`、訳語の統一は `6e7d8dc0d93e7f1a5fa1c034d554fe7fd5955756`

## 1. 互換の範囲

- 出力した PNG は、本家（Standard）125.0.1 で読み込める（2026-10-23、利用者の環境で確認）
- これは高さの画像の互換で、OTRP と本家のセーブデータの互換ではない
- 湖の水位・建物・道路などを含めて残したいときは、セーブデータを使う

## 2. 読み込み処理の決まり（混同しやすい所）

`simworld.cc` の読み込み処理で確かめた（2026-10-23）。

- W×H 画素は W×H タイルに当たる。ゲームの地形は (W+1)×(H+1) 個の頂点を持つ
- 読み込みは、デコードした高さに +1 し、右端・下端の頂点を複製してから、斜面と海岸を補正する。先頭の頂点の扱いもある。
  そのため、**PNG をデコードし直しただけでは、ゲーム内の地形が一致するとは言えない**
- 読み込みのモード（線形）・高さの上下限・海面水位は PNG の中に入らない。配るときは別に伝える

## 3. 出力の決まり

- 今の設定の高さの下限・上限を使った、線形（linear）向けの逆変換
- 表せない高さは、いちばん近い値にする。保存画面に、変わった数と最大の誤差を出す。標高を自動で引き伸ばすことはしない
- 画面の「高さの誤差」は、画素にすることと線形の変換による分。「外周の変化数」は複製する前の頂点との差で、ゲームを初期化した後の変化の総数ではない
- 回した地形（90 度回転してから出力）では、読み込み直すと頂点が変わることがある（記録の表。既存の読み込み処理の限界として画面に書いてあり、読み込み側は変えていない）

## 4. 自動テストが保証する範囲

`simutrans/tests/test_heightmap_export.py` は、実際の出力処理・PNG のコーデック・高さの読み込み・ファイル操作の実装を使う。
world のデータと GUI の入力先はアダプターなので、**本体の初期化と斜面の補正までは保証しない**。

確かめているもの: 高さの変換の境界値、異なる上下限、正方形でないときの画素の順、負の値、外周で失われる分、日本語のパス、
既存ファイルの保護、rename の失敗、最後の fclose の失敗、短いファイル名と 127/128 バイトの境目。

本体の初期化を通した往復（読み込み → 出力 → 読み込み）は、検証専用のバイナリで別に確かめた（記録）。そのフックとデータは製品のコードに入っていない。

## 5. GUI の確認

- MCP の `gui.get_windows()`・`gui.get_window_components()`・`gui.click()` と画面のキャプチャで、保存画面・文字切れ・日本語・成功の通知・既存ファイルの拒否を確かめられた
- ゲームオプションから新規マップ作成へ移るモーダル画面では、MCP の応答が止まった。世界の初期化を通す確認は MCP ではできない

## 6. 日本語の用語の決まり

**新しい訳語を付ける前に、既存の公式 UI・`ja.tab` にある名前を探して、それを使う。** 対象の OTRP と本家の配布版の両方の翻訳・既存の UI と照らす（2026-10-26、利用者の方針）。

| 使わない | 使う名前 | 根拠 |
|---|---|---|
| 高さマップ・高さ画像 | 地形データ | 既存の `Lade Relief` の訳「地形データを読み込む」 |
| 海面高 | 海面水位 | 既存の `Water level` の訳 |
| 湖の水位 | 湖面水位 | 本家 125.0.1 の `Lake height` の訳 |
| 読込モード | ロードモード | 本家 125.0.1 の `Load mode:` の訳 |
| linear（日本語の画面） | 線形 | 本家 125.0.1 の `linear` の訳 |

- 既存のキーがあるなら、新しいキーを作らず再利用する（海面水位は独自の `Sea level:` をやめて `Water level` を使った。保存完了の通知は `Load mode:` と `linear` を組み合わせる）
- OTRP に無く本家にある訳（`linear`）は、配布版に合わせて足す
- 対応する定義が見つからないもの（高さの下限・上限、最大誤差、外周の変化数）は、説明の言い方のままにする。英語が似ているだけの別の機能の訳語を流用しない
